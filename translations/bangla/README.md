# ৯০ দিনের সাইবার সিকিউরিটি স্টাডি প্ল্যান

৯০ দিনের সাইবার সিকিউরিটি চ্যালেঞ্জে স্বাগতম!
এই রিপোজিটরিটি একটি সুসংগঠিত ৯০ দিনের self-study plan প্রদান করে, যা সাইবার সিকিউরিটি ক্ষেত্রে একটি শক্তিশালী base তৈরি করতে শিক্ষার্থীদের সাহায্য করার জন্য ডিজাইন করা হয়েছে। আপনি যদি এই ক্ষেত্রে প্রবেশ করতে চান এমন একজন নবীন শিক্ষার্থী হন, অথবা আপনার skill বাড়াতে চান এমন একজন পেশাদার হন, এই রোডম্যাপটি সহায়ক হবে। এটি বাছাইকৃত রিসোর্স, প্র্যাকটিক্যাল টাস্ক এবং শেখার উপকরণ সরবরাহ করে।

## ভূমিকা

দৈনিক মডিউলগুলোতে মৌলিক এবং উন্নত বিষয়গুলো অন্তর্ভুক্ত থাকে, যার মধ্যে রয়েছে:

- নেটওয়ার্কিংয়ের মৌলিক ধারণা (Network+)
- সিকিউরিটির মূলনীতি (Security+)
- Linux-এর মৌলিক ধারণা এবং Shell স্ক্রিপ্টিং
- Python সিকিউরিটি প্রোগ্রামিং
- ট্রাফিক অ্যানালাইসিস এবং প্যাকেট ইনস্পেকশন
- Git ভার্সন কন্ট্রোল
- SIEM টুলস এবং ELK লগ অ্যানালাইসিস
- GCP, AWS এবং Azure ক্লাউড সিকিউরিটি
- পেনিট্রেশন টেস্টিং এবং এথিক্যাল হ্যাকিং

প্রতিটি দিনের জন্য প্র্যাকটিক্যাল টাস্ক, টিউটোরিয়াল এবং পড়ার উপকরণ ডিজাইন করা হয়েছে। সম্পূর্ণ রিসোর্সের তালিকার জন্য [`learn.md`](../../learn.md) দেখুন।

## লক্ষ্য এবং টার্গেট অডিয়েন্স

### লক্ষ্য

এই ৯০ দিনের পরিকল্পনার প্রধান লক্ষ্য হলো শিক্ষার্থীদের সাহায্য করা:

- সাইবার সিকিউরিটির মূল ধারণা এবং প্র্যাকটিসের ক্ষেত্রে একটি শক্তিশালী ভিত্তি তৈরি করা।
- দৈনিক অনুশীলন এবং বাস্তব টুলস ব্যবহারের মাধ্যমে হাতে-কলমে অভিজ্ঞতা অর্জন করা।
- CompTIA Network+ এবং Security+-এর মতো সার্টিফিকেশনের জন্য প্রয়োজনীয় প্রযুক্তিগত দক্ষতা গড়ে তোলা।
- সাইবার সিকিউরিটি, সিস্টেম হার্ডেনিং, ক্লাউড সিকিউরিটি, স্ক্রিপ্টিং এবং এথিক্যাল হ্যাকিংয়ের মতো মূল ক্ষেত্রগুলো অন্বেষণ করা।
- ৯০ দিনের মধ্যে ধারাবাহিক শেখার অভ্যাস গড়ে তোলা।

### টার্গেট অডিয়েন্স

এই রিপোজিটরিটি যাদের জন্য উপযুক্ত:

- entry-level চাকরি বা সার্টিফিকেশনের প্রস্তুতি নেওয়া সাইবার সিকিউরিটি পেশাদারদের জন্য।
- সিকিউরিটি ফিল্ডে ক্যারিয়ার পরিবর্তন করতে চাওয়া আইটি (IT) পেশাদারদের জন্য।
- কম্পিউটার সায়েন্স, ইনফরমেশন সিস্টেম বা নেটওয়ার্ক ইঞ্জিনিয়ারিং অধ্যয়নরত শিক্ষার্থীদের জন্য।
- একজন self-learner এর জন্য।
- সিকিউরিটি ইনফ্রাস্ট্রাকচার(Security Infrastructure) এবং থ্রেট ডিটেকশন(Threat Detection) ভালোভাবে বুঝতে চাওয়া ডেভেলপার এবং DevOps ইঞ্জিনিয়ারদের জন্য।

পূর্ববর্তী কোনো অভিজ্ঞতার প্রয়োজন নেই, তবে কম্পিউটার, নেটওয়ার্কিং বা প্রোগ্রামিং সম্পর্কে মৌলিক ধারণা থাকলে তা সহায়ক হবে।
